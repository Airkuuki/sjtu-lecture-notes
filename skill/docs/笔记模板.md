# 笔记模板

> 这是**你拥有**的产出规范。Agent 按这个结构写笔记，想改格式直接改本文件。
> 写笔记的硬规则见仓库根目录 `SKILL.md`。

---

## 五条原则

1. **按讲课时间顺序排** —— 章节顺序 = 老师讲的顺序，不按知识点重新归类
2. **不出现时间戳** —— 正文不挂 `[mm:ss]`，也**不做时间轴附录**；笔记要能当复习资料直接读
3. **只写重点 + 可以放老师原话** —— 闲聊不写；老师的关键表述用引用块原样保留
4. **必须写出「引入过程」与「推导过程」** —— 见下
5. **正文用书面语（讲义体）** —— 见下

### 关于第 5 条

正文的语体应与教材、讲义一致：

| 不用（口语） | 改用（书面） |
|---|---|
| 怎么引出来的 / 为啥 | 概念的引入 / 原因在于 |
| 切一刀、看轮廓 | 作截面、考察截线 |
| 坑、容易扣分 | 易错之处、需特别注意 |
| 把…挤掉（正文转述时） | 积去一个变量 |
| 就得把…加起来 | 对…求和 |
| 搞定、东西、咱们、啥 | （删除或改写为具体表述） |
| 难点在积分区域 | 关键在于确定积分区域 |

要求：陈述用"设/由…可得/代入得/从而/即/此处易出错"，少用语气词与感叹号。

**例外**：老师原话保留口语原样（那是引用，且正是其价值所在），
但必须放在引用块里并标明是原话，不要与正文转述混在一起。

### 关于第 4 条（最容易偷懒、也最影响复习价值）

- **引入过程**：每个新概念都要交代"老师是怎么引出来的"——
  从哪个已有知识出发 → 提出了什么问题 → 为什么必须这样定义。
  例如联合分布函数不是凭空给的，而是先回顾一维 $F(x)=P(X\le x)$，
  再问"两维时点落在哪"，最后才定义 $P(X\le x, Y\le y)$。
- **推导过程**：每个公式、性质、关系式都要给出**推导或证明**，不能只写最终式。
  判断标准是：**只看这份笔记，读者能否明白该式子为什么成立？**

  | 类型 | 要求 |
  |---|---|
  | 定义 | 说清引入动机（从哪个旧知识出发、要解决什么问题） |
  | 性质（单调性、归一性…） | **给出证明**（如事件包含关系、积分中值定理），不能只列结论 |
  | 关系式（密度 ↔ 分布函数） | 写出求导/积分步骤，标明用到的定理 |
  | 型公式（条件密度等） | 给出**严格推导**；仅有直观解释不算完成 |
  | 例题 | 分步写，中间结果要出来 |

  **老师课上只给直观、未给证明时，笔记要把证明补出来，并标注"此处为笔记补充"。**
- **老师没讲但必要的补充**要标注清楚（如"这一点老师没展开，是本笔记补充的"），
  不要把补充内容混进"老师原话"里。

> 一句话：只给结论的笔记等于抄书。看不到"这个式子为什么成立"，笔记就没法用来复习。

> **附录只保留「板书帧速览」一个，且必须是图片，不是表格。**
> 每帧一行简短说明，紧接一块图片（绝对路径，直接引用数据盘原图）：
>
> ```markdown
> **板书 0043**（21:00）一维与二维对照，及例题完整推导
>
> ![](帧/<节次>/board/frames/f_00043.jpg)
> ```
>
> 不再生成「时间轴索引」与「识别修正记录」：
> - 时间轴对复习没用，还让笔记读起来像流水账；
> - ASR 修正的逐条留痕属于过程性记录，读者不需要。
> 术语按上下文直接改正即可（改正后的笔记本身就是要交付的东西），
> 但**老师原话必须逐字来自字幕**，只是不再做修正登记表。

## 判定"什么是重点"

按优先级：

1. **老师明确提示**："这个考试会考""注意""容易错""这个要会"
2. **老师反复强调或专门点题**："这一章的重点是……"
3. **定义、定理、主公式**
4. **例题的解法要点**（尤其是积分区域、缩放因子这类关键步骤）
5. **结构性内容**：从上一章到这一章的推广脉络

## 不要写进笔记的

- **闲聊**：排课吐槽、天气、食堂、课后聊天
- **时间戳堆砌**：正文里不要每条都挂 `[mm:ss]`
- **大段原始转写**：材料包里有全文
- **没有依据的推断**：宁可写"（听不清）"
- **润色过的"原话"**：引用老师原话必须逐字来自字幕
